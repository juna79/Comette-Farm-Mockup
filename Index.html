How the weekly dashboard works

Designed around the existing Comette Farm email/Excel workflow.

From Excel list to simple order

Customers no longer need to manually fill a spreadsheet. They choose their delivery route, add quantities from the weekly list, and send one clean order summary to the office.

  • Monday list can go to Tigoni customers for Wednesday delivery.
  • Tuesday list can go to Muthaiga customers for Thursday delivery.
  • Routes and cut-off days can be changed each week.

Recipes make the list easier to shop

Instead of only sending stock, Comette can inspire customers with meals based on what is available that week. Each recipe has a method plus an “add ingredients” button.

This keeps the current operational model while making ordering feel more premium and much easier.
